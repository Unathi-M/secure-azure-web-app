# Secure Azure Web Application with Threat Detection

## Project purpose

This portfolio project demonstrates how to deploy, secure, monitor, and investigate a small Azure web application environment.

## Planned architecture

- Frontend web tier hosted on Azure App Service
- Backend application tier protected with private networking
- Azure SQL Database data tier
- Azure Virtual Network with separated networking functions
- Microsoft Entra ID, RBAC, and MFA
- Azure Monitor, Log Analytics, Application Insights, and Microsoft Sentinel
- Bicep Infrastructure-as-Code stored in GitHub
- Controlled simulated brute-force detection and incident response

## Current status

Project workspace initialized. Azure application resources have not yet been deployed.

## Security warning

This is a learning and portfolio environment, not a production system. Never commit passwords, tokens, connection strings, `.env` files, certificates, or private keys.
